# Mastery Model

## Overview
The Mastery Model defines the strict, deterministic rules for advancing a learner's state based on observable evidence.

## Core Rules
- Mastery cannot be guessed or generated by an LLM (e.g., "Mastery = 87%").
- Mastery is advanced via a rules engine evaluating a chronological list of `EvidenceRecord`s.

## State Machine
A `TopicMastery` transitions through states (`NOVICE`, `FAMILIAR`, `PROFICIENT`, `MASTERED`).

**Transition Rules:**
1. **NOVICE -> FAMILIAR**: Requires multiple independent PASS outcomes on conceptual questions (which includes intuitions, bounds recognition, and correctness).
2. **FAMILIAR -> PROFICIENT**: Requires multiple independent PASS outcomes on implementation and reasoning questions (which includes formal Derivation, Code Implementation, Complexity Analysis, and Optimization).
3. **PROFICIENT -> MASTERED**: Requires passing independent Transfer Problems and demonstrating long-term retention via successful Retrieval Practice.

*Note: Derivation and Optimization evidence are classified under "Implementation Reasoning". While crucial to the pedagogical Golden Measure pipeline, they do not dominate the mastery score alone; they combine with raw implementation and edge-case correctness to prove proficiency.*

## Dependencies
Depends on the `Evidence Model` for input. Mutates the `Learner Model` as output.
