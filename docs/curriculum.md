# DSA Curriculum Graph

The curriculum is structured strictly sequentially to ensure foundational mastery before advancing. We only implement topics in small, verified vertical slices to maintain quality.

```mermaid
flowchart TD
    foundations[Foundations] --> arrays[Arrays]
    arrays --> strings[Strings]
    strings --> linear_search[Linear Search]
    linear_search --> binary_search[Binary Search]
    binary_search --> two_pointers[Two Pointers]
    two_pointers --> prefix_sum[Prefix Sum]
    prefix_sum --> sliding_window[Sliding Window]
    sliding_window --> hashing[Hashing]
    hashing --> sorting[Sorting]
    sorting --> linked_lists[Linked Lists]
    linked_lists --> stacks[Stacks]
    stacks --> queues[Queues]
    queues --> trees[Trees]
    trees --> heaps[Heaps]
    heaps --> recursion[Recursion]
    recursion --> backtracking[Backtracking]
    backtracking --> graphs[Graphs]
    graphs --> greedy[Greedy]
    greedy --> dynamic_programming[Dynamic Programming]
    dynamic_programming --> advanced[Advanced]
```
