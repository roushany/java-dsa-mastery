# Source Registry

This registry tracks the primary and authoritative sources used for defining concepts, constraints, and implementations across the curriculum.

## Claim Types
All claims logged here must be categorized as:
- **[VF] Verified Fact**
- **[IN] Interpretation**
- **[PS] Pedagogical Simplification**
- **[IR] Implementation Recommendation**

## Authority Hierarchy
1. **Java Ecosystem:** Java Language Specification (JLS), Java Virtual Machine Specification (JVMS), OpenJDK Documentation.
2. **Algorithms/DSA:** Reputable academic publications, established textbooks (e.g., CLRS, Sedgewick), university lecture materials.
